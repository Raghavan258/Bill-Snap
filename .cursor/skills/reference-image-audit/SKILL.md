---
name: reference-image-audit
description: Audits supplied Bill Snap images and checks implementation against them.
---
1. List and inspect supplied image files.
2. Identify which flow each depicts: Record Expense, Add Income, Start Saving.
3. Extract screen order, labels, actions, form fields, sheet options, and navigation.
4. Separate approved decisions from accidental generated-image details.
5. Flag inconsistencies with `/AGENTS.md`.
6. Produce a screen-by-screen implementation checklist.
7. Compare implementation screenshots and report hierarchy, spacing, typography, contrast, and behaviour mismatches.
Do not assume visual presence means a feature is implemented.
